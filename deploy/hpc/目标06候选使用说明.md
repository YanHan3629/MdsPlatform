# 目标 06 候选使用说明

目标 06 候选位于同济 HPC 的 `/share/home/u08162/apps/mds-feature06-20261126`。候选以交付版 3733654 为起点，使用独立业务存储。固定交付版通过仓库的 `deploy/hpc/delivery.ps1` 启动。候选的具体工件、作业和验收状态见本轮执行记录。

## 启动与停止

连接校园网或 VPN，在仓库根目录打开 PowerShell 7。以下命令使用目标 06 的候选路径。若验收会话已经排队或运行，先查询状态，再连接当前会话。

```powershell
$session = '.\deploy\hpc\session.ps1'
$candidate = @{
    WorkspaceRoot = '/share/home/u08162/apps/mds-feature06-20261126'
    Server = '192.168.212.236'
}
& $session @candidate -Action Status
```

核对安装记录后，按所需功能启动一次。数据管理、上传、预览和检索可用 CPU。问答需使用 A800，会话使用交付版的 Qwen3.8-27B-FP8 模型。

```powershell
$run = & $session @candidate -Action Start -Mode GPU -GpuType A800 -QaProfile standard -Minutes 60
# 数据管理可改用以下命令
# $run = & $session @candidate -Action Start -Mode CPU -Minutes 60
$jobId = $run.job
```

连接已有会话时，把 `$jobId` 设为首次状态查询列出的作业号。查询指定作业，等到 `ready=True` 后，在同一个 PowerShell 窗口运行 `Connect`。

```powershell
& $session @candidate -Action Status -JobId $jobId
& $session @candidate -Action Connect -JobId $jobId
```

保持连接窗口运行，在浏览器打开页面。 [产业链数据空间平台](http://127.0.0.1:18888/data-space/index.html)

使用结束后，在连接窗口按 `Ctrl+C` 关闭隧道。停止自己启动的作业并复查，等到 `active=False` 且 `accounting` 中出现终态。

```powershell
& $session @candidate -Action Stop -JobId $jobId
& $session @candidate -Action Status -JobId $jobId
```

回到固定交付版时，结束候选会话和隧道，再从 `delivery.ps1` 启动交付版。

## 页面操作

1. 在统一登录页使用所分配的账号。左下角显示账号绑定的企业。业务节点由账号可见数据集的已登记分类产生。
2. 在总览点击一个或多个业务。数据集按选中业务取并集，再应用名称和状态筛选。使用“清除业务筛选”恢复当前身份可见的数据集。
3. 每个数据集占一行。有预览权的行优先显示并自动读取首批内容图。通过“下一组”浏览后续文件，通过图片按钮放大已授权的缩略图。切换本行版本时，图片随冻结范围更新。目录权限只开放允许查看的目录信息。
4. 在总览打开“上传、发布与索引任务”或“授权视图导出”。入口取决于对应操作权限。问答附件仍在问答表单中。需要核验原件时，在对应来源卡按独立的原件下载权限操作。
5. 在检索或问答中搜索并选择数据集，核对标签中的企业、版本和索引。每次最多选择八个数据集，同一个数据集选择一个冻结版本。检索硬条件要适用于每个选中范围，页面会提示不兼容的选择。使用仅附件模式时，问答只读取本次附件和补充文字。
6. 问答页面显示排队、依据读取和生成状态。可取消当前请求后重新提交。已完成答复中的来源卡沿用提交时的冻结范围。即使后来从选择器移除了某个数据集，仍可在授权有效时点击“查看完整证据”核对原文或原行。

## 容量和读取条件

- 标准问答档位一次执行一个请求，最多四个等待。达到容量时页面显示队列已满。标准档位的请求截止时间为 180 秒。
- 范围上限由候选的 `qa-capabilities.json` 中 `maxDataScopes` 配置，默认 8。修改后需使用同一配置重新构建部署，让浏览器与两个服务读取一致的值。
- 多集提交需要每个范围均可访问并有就绪索引。筛选条件须适用于所有选中的检索范围。草稿或索引失败版本的总览内容图使用文件预览权限。
- 原件下载权限与来源预览权限独立。授权到期或撤销后，页面清除受保护的内容，旧图片地址及来源不能继续读取。

管理员可维护账号与授权。业务读取仍按有效资源授权和岗位能力校验。需补充分类时，由有权维护者在对应数据集行填写中文显示名称、业务类型和可追溯依据。
