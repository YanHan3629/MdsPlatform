# 产业链数据空间平台前端

静态前端页面，已接入后端 `/api/data-space` 闭环接口。

## 访问方式

- 直接打开：`services/frontend/index.html`
- 后端启动后访问：`http://localhost:8888/data-space/index.html`

## 本次场景

- 链主企业：海尔智家，作为数据消费方。
- 业务供给方：营销、服务、零售、客服、渠道销售、采购、制造、研发、质量、物流、供应链、财务、企划、法务、人力、战略、IT。
- 示例数据统一采用家电产业链、智能冰箱、冰箱质检、冰箱供应链、冰箱售后服务等场景。

## 关键约束

创建数据资源时必须选择后端白名单业务域；如果未选择或选择无效业务域，后端会拒绝创建。
