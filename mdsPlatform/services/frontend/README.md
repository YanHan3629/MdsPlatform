# 产业链数据空间平台前端

静态前端页面，已接入后端 `/api/data-space` 闭环接口。

## 访问方式

- 当前交付版本通过同济HPC运行。按[交付版使用说明](../../../deploy/hpc/交付版使用说明.md)启动并建立SSH隧道后，访问：`http://127.0.0.1:18888/data-space/index.html`。
- 未登录时先显示独立登录封面；完成身份确认后才能进入正式功能页。问答页深链接为 `http://127.0.0.1:18888/data-space/index.html#qa`。

前端使用数据空间账号及对应企业的授权范围，支持文本、图片、数据空间问答及来源查看。前端通过同源 `/api/data-space/qa` 接口通信，不能通过直接双击HTML文件完成登录和问答。`start-all.ps1`和本地8888端口属于历史Docker部署；当前交付使用 `deploy/hpc/delivery.ps1`。可演示问题及其数据范围见[交付版问答题目清单](../../../deploy/hpc/交付版问答题目清单.md)。

## 本次场景

- 当前家电产业链示例包含供应、制造、仓储、运输、客户和售后等企业职责范围，实际可见数据由账号及资源授权决定。
- 订单、供应批、制造批、成品批、交付行及服务工单通过业务编号关联；支持程度以所选索引和已验证题目为准。

## 关键约束

创建数据资源时必须选择后端白名单业务域；如果未选择或选择无效业务域，后端会拒绝创建。
